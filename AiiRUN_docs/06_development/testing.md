- Integration
- UI / E2E
- Media compatibility
- Regression
- Performance

- Project save/load
- Undo/Redo

- Offline media/relink
- Preview
- Audio sync
- Render determinism
- Crash recovery
- Plugin compatibility
- Cross-platform behavior
