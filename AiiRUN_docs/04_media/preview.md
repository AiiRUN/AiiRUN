# Preview

Preview is optimized for interaction rather than final quality.

Scheduler priority:
1. Current frame
2. Playback
3. Lookahead
4. Nearby timeline
5. Background

Quality:
Auto / 1/4 / 1/2 / 3/4 / Full / Custom

Proxy:
Off / Ask / Auto Heavy / Always

Preview may use proxy media while final rendering uses original media.
