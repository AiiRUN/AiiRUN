# Object System

Everything the user edits is an Object.

Types:
- Video
- Image
- Audio
- Text
- Shape
- Subtitle
- Group
- Composition
- Adjustment
- Generator

Object data:
- id
- type
- name
- assetRef
- time
- transform
- properties
- keyframes
- effects
- relationships
- metadata
- state

Assets and Objects are separate concepts.

Composition owns its own timeline and can itself appear as an Object.

Relationships:
- Parent
- Follow
- Align
- Constrain
- Offset
- Look At
