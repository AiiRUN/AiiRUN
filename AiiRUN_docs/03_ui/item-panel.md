# Item Panel

Item is the control center for the selected Object.

> Item = 選択したObjectのコントロールセンター

Video tabs may include:
- Basic
- Effects
- Color
- Mask
- Animation

Text tabs may include:
- Text
- Font
- Layout
- Effects
- Animation

Audio tabs may include:
- Basic
- Effects
- EQ
- Volume
- Automation

Image tabs may include:
- Basic
- Effects
- Color
- Mask
- Brush

Effects use an Effect Browser with search, favorites, categories, built-in effects, official extension effects, and third-party plugin effects.

Applied effects appear as an editable, reorderable stack.
