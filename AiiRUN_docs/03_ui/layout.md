# UI Layout

Menu bar:
File / Edit / View / Project / Object / Effect / Audio

Upper area:
Project / Media / Preview / Item

Toolbar:
- Default: between upper workspace and Timeline
- Future configurable positions: Top / Middle / Bottom
- Middle is default

Normal toolbar:
Select / Split / Add / Undo / Redo / More

Text selected:
Select / Text / Font / Size / Align / Color / Animation

Image selected:
Select / Crop / Mask / Brush / Color / Transform / More

Audio selected:
Select / Split / Volume / Fade / EQ / Audio / More

Advanced items belong under More.
