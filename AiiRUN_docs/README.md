# AiiRUN Documentation

AiiRUN is a cross-platform video editor designed around:

> 最高のオールラウンダー。それがこいつ。

Product philosophy:

> 誰でもすぐ使える。使い込むほど、どこまでも自由になる。

Core UI principle:

> 機能を削除するのではなく、必要になるまで隠す。

This folder records product vision, architecture, UI, media, features, development, roadmap, and decisions.
