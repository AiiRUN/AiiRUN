# Roadmap

## Phase 1 — Foundation
Tauri 2, React/TypeScript, Rust core, project model, basic UI shell.

## Phase 2 — Editing
Object system, Timeline, selection, move/trim/split, Undo/Redo, media import, Preview.

## Phase 3 — Core media
FFmpeg, audio, effects, color, export, cache/proxy.

## Phase 4 — Professional workflows
Keyframes, masks, composition, graph editor, advanced audio/color, image workspace.

## Phase 5 — Extensibility
Plugin SDK, Plugin Manager, official extension packages, Developer Mode.

## Phase 6 — AI
Provider system, AI proposals, AI-assisted editing.

## Phase 7 — Polish
Performance, accessibility, cross-platform QA, recovery, installer/updater, documentation.
