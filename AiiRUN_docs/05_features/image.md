# Image Editing

Image Workspace:
- Layer visibility
- Lock
- Opacity
- Blend modes
- Masks
- Effects
- Transform
- Selection
- Brush
- Non-destructive editing

Selection:
Rectangle / Ellipse / Freehand / Polygon / Magic Wand / Color Select / Lasso / Object Select

AI segmentation/background removal produces an editable mask.

Brush:
Size / Hardness / Opacity / Flow / Spacing / Texture / Pressure

Future:
Tilt / Eraser / Presets

Video frames can be used for thumbnail editing.
