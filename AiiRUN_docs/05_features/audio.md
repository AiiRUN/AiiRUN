# Audio

Audio uses sample-accurate timing.

Audio Object may contain source, start, duration, volume, pan, speed, fade, effects, keyframes, and automation.

Features:
- Track/master mixer
- Buses
- Voice/Music/SE routing
- Waveform cache
- Time stretch
- Pitch
- EQ
- Compressor
- Limiter
- Noise Gate
- Reverb
- Delay
- Distortion
- Noise Reduction
- Plugin effects
- Ducking
- Peak/RMS/LUFS/True Peak metering
- Clipping warnings
