# Product Philosophy

- Anyone can start immediately.
- The more the user learns, the more freedom becomes available.
- Features are hidden until needed rather than removed.
- Performance options should be selectable rather than forced.
- Additional capabilities can be installed later.
- Advanced workflows should remain compatible with simple workflows.

Performance:
> 軽さを押し付けない。性能を活かす選択肢を与える。

Modularity:
> 必要になった機能は、あとから追加できる。
